# Ai-Subtitler Latency Blind Test Results

This document records the results of systematic, blind, user-driven latency preference tests for Ai-Subtitler. Each section is dedicated to a specific model and language configuration. Please add new results as further tests are performed.

## Model: ggml-tiny.en.bin (English, Tiny)

**Test Date:** 2026-02-24

**Test Method:**
- Blind, adaptive A/B coupled tests
- User was presented with randomized pairs of latency settings and selected their preference without knowing the values
- Process repeated until a clear preference emerged

**Preferred Latency Settings:**
- `--voice-stop-ms`: **900**
- `--voice-gate-check-ms`: **300**

**Notes:**
- These values yielded the best perceived latency and user experience for the English tiny model on this date.
- Further tests are encouraged for other models and languages. Please add new sections below as needed.
